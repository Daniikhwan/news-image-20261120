One image summing up the world news of Friday 20 November 2026.

`main.py` (Python 3.13, standard library only, no network) draws the
infographic and writes it to `$MAKEFUN_OUTPUT_DIR/entry.png`
(default `./out/entry.png`). The output is deterministic: two runs write
byte-identical PNG files.
